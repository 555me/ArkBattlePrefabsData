# ArkBattlePrefabsData


明日方舟战斗预制体数据<br/>
本仓库文件名均为该文件原始PathId。<br/>
使用方法：<br/>
如需查找特定单位的预制体数据，先在'assets_list.json'内查找单位id，再根据PathId查找对应文件。<br/>
如需查找某一文件属于哪个单位，可以直接在'assets_list.json'内查找文件名前5~7位，通常不会存在前5位重复的文件。<br/>
<br/>
当前MonoScript文件hash/md5：'1cc3'，如有需要，可在[hot_update_list.json](https://github.com/555me/ArknightsAppData/blob/main/hot_update_list.json) 中查找该hash/md5所对应的文件并下载提取。
